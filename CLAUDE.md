## Agent skills

### Issue tracker

Issues are tracked in GitHub Issues on `danielholmes/ludeum`, using the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five default labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.

### Windows ROMs

Getting a Windows game to run under Wine is done by hand, outside Ludeum, and handed over as a prepared folder with a `launch.json`. See `docs/agents/windows-roms.md`.
