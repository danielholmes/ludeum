# A Bundle is not a Game: its Copies are Copies of the Games it contains

A Bundle is one release of several games that were each also released on their own, on its Platform or another: Command & Conquer: The First Decade, Super Mario All-Stars, Ninja Gaiden Trilogy, Konami GB Collection Vol. 1. It is its own kind of thing, not a Game. It has an IGDB link (or none, when made by hand), a Cover, Copies (ROMs included), Attachments and a Highlight note, and it contains Games on its Platform. It has no Rating, Playthroughs, Intent, Childhood or Battles. Each of its Copies is one Copy, recorded once, that also counts as a Copy of every Game it contains: it shows in their Copies, makes them Owned, can be named by their Playthroughs, and its ROM is what Play opens for them, with each Game's own Emulator settings. Its Attachments and Highlight note show on its Games too.

We considered a Game with a "bundle" flag that hides what doesn't apply. We chose against it because nearly every Game rule would then need an exception ("every rated Game takes part in Face-off", "a Game can have Playthroughs"). We also considered recording one Copy per contained Game, which needs nothing new. That is what I'd been doing by hand ("compilation after the Warcraft 2 swap", copied onto five Copies), and it duplicates the price and where it came from, and needs five Gone marks for one box.

Being a Bundle is my call, not IGDB's. IGDB types single-game releases such as Kirby Super Star as bundles, and even lists contents for it, so neither IGDB's type nor its contents decide. Matching therefore never makes a Bundle: a ROM whose IGDB game is already a Bundle in the journal is Matched to that Bundle, and otherwise it makes a Game, as before (ADR 0004). A Game a Bundle contains may link to an IGDB game that isn't on its Platform, because IGDB's contents for some Bundles are the original releases (Metal Slug 6 in the PSP's Metal Slug Anthology is an Arcade and PS2 game in IGDB). No two Games on a Platform share an IGDB link.

There is no action to turn a Game into a Bundle. The Games that were already Bundles became Bundles in a one-off migration, which dropped Super Mario All-Stars' Rating.

In the journal a Bundle is a `game` row marked as one, with `bundleGame` saying which Games it contains. That way it shares, with no second copy of the code, everything it has in common with a Game: the IGDB link and its uniqueness, the Cover, Attachments, Highlight note, Copies and ROM Matching. The price is that every screen that lists Games leaves Bundles out, which the Library query does once for all of them.

The code says so too: a Bundle is a `Game` whose `isBundle` is set, held by its `GameID`, and the screens a Bundle shares with a Game (its page, Assign to Game) ask that flag. A type of its own would mean a second copy of every Game read and write a Bundle uses, for no rule the flag gets wrong.
