# An Automatic Match needs the checksum and the name to agree

A checksum lookup through Hasheous is not trusted on its own. A dry run of the first Import against my library found that about 2% of checksum matches pointed at the wrong IGDB game: sequels and spin-offs linked to the original (*Super Star Wars: Return of the Jedi* → *Super Star Wars*, *Battletoads & Double Dragon* → *Battletoads*), and some linked to bundles. So a ROM is only linked automatically when its checksum identifies an IGDB game *and* its name matches that game's name or one of its alternative names, after normalising. It is never linked to an IGDB bundle. Anything else goes to the Review queue as a suggestion. That keeps our assumption that Matches don't need correcting afterwards, at the cost of about 50 extra one-click confirmations.
