# A Game with no ROM finds its Box art by name

Superseded by [0020](0020-launchbox-is-the-only-source-of-box-art.md): every Game, with ROMs or none, finds its Box art by title in the LaunchBox Games Database; libretro-thumbnails is gone. What stays true is that the lookup isn't kept in the journal and the box is for the Game's Copies' Regions.

Box art used to come only from a Game's ROMs: each ROM is looked up in its Platform's libretro-thumbnails listing by its file name, and a Game with no ROM fell through to IGDB's Cover art. That left the PS1 discs and Wii games I own or once owned, recorded as hand-made Copies, showing IGDB's clean artwork beside their neighbours' branded boxes, which is the look [0006](0006-box-art-before-igdb-cover-art.md) chose Box art for. Now a Game with no ROM, on a Platform with a ROM folder (now any Platform libretro has a repo for; see the amendment below), looks for its Box art by title alone: the name it shows, then IGDB's, then its own, matched the way a ROM's fuzzy lookup is. The box is for the Regions on its Copies, Gone ones included, since that's the box I had, else USA, Europe, Japan, the same fallback a ROM with no region tag gets.

Unlike a ROM's, the lookup isn't kept in the journal. It runs each time the Cover is shown, against the listing in the cache (indexed once per launch), so renaming the Game, changing its IGDB link or editing a Copy's Regions changes its Box art with no step to rerun, and there's no migration. Once a Game has a ROM, its ROMs decide, as before, even when none of them has Box art. A listing that can't be read finds nothing for now, so IGDB's Cover art shows until it can, as it does for a ROM not yet looked up.

A title match with no file name is the weakest lookup there is, and a wrong one is accepted silently, as 0006 already accepts for ROMs: an upload fixes it. Platforms with no ROM folder (PC, the Xbox and PlayStation 3 and later) stay on IGDB's Cover art. libretro has repos for some of them, but none is mapped yet.

**Amended 2026-10-08:** leaving out the Platforms with no ROM folder was a mistake, since their Games are exactly the ones that never have a ROM. Every Platform libretro-thumbnails has a repo for now looks for its Games' Box art by title the same way, whether or not it has a ROM folder: the original Xbox, Dreamcast, Wii U, 3DS, Atari, Commodore and the other retro Platforms. The Xbox 360, PS3 and PS4 repos have only a few dozen boxes between them, so most of those Games still show IGDB's Cover art. PC, Mac, the Switch and the Xbox One and later have no repo, so they always do.

**Amended 2026-10-16:** libretro has no Windows repo, but PC Games now look for their Box art in the DOS repo, which has the Windows 95 era's boxes too (Command & Conquer: Red Alert). Without it, a PC Game in a Bundle showed the Bundle's box rather than its own. A PC Game DOS has no box for (Red Alert 2, Half-Life) still shows IGDB's Cover art, or its Bundle's Cover.

**Amended 2026-10-16:** a Game with no ROM that libretro and LaunchBox find no box for by its names is looked up again by IGDB's alternative names for it; see [0018](0018-launchbox-box-art-after-libretros.md).
