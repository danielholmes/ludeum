# A Game with no ROM finds its Box art by name

Box art used to come only from a Game's ROMs: each ROM is looked up in its Platform's libretro-thumbnails listing by its file name, and a Game with no ROM fell through to IGDB's Cover art. That left the PS1 discs and Wii games I own or once owned, recorded as hand-made Copies, showing IGDB's clean artwork beside their neighbours' branded boxes, which is the look [0006](0006-box-art-before-igdb-cover-art.md) chose Box art for. Now a Game with no ROM, on a Platform with a ROM folder, looks for its Box art by title alone: the name it shows, then IGDB's, then its own, matched the way a ROM's fuzzy lookup is. The box is for the Regions on its Copies, Gone ones included, since that's the box I had, else USA, Europe, Japan, the same fallback a ROM with no region tag gets.

Unlike a ROM's, the lookup isn't kept in the journal. It runs each time the Cover is shown, against the listing in the cache (indexed once per launch), so renaming the Game, changing its IGDB link or editing a Copy's Regions changes its Box art with no step to rerun, and there's no migration. Once a Game has a ROM, its ROMs decide, as before, even when none of them has Box art. A listing that can't be read finds nothing for now, so IGDB's Cover art shows until it can, as it does for a ROM not yet looked up.

A title match with no file name is the weakest lookup there is, and a wrong one is accepted silently, as 0006 already accepts for ROMs: an upload fixes it. Platforms with no ROM folder (PC, the Xbox and PlayStation 3 and later) stay on IGDB's Cover art. libretro has repos for some of them, but none is mapped yet.
