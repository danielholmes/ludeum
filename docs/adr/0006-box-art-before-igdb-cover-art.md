# Box art before IGDB's cover art

A Game's Cover is real box art when there is any: my upload, else libretro-thumbnails' box scan, else the box art OpenEmu holds, and only then IGDB's cover art. This reverses the first spec's "IGDB always wins". IGDB's covers are clean artwork without the platform branding (the NES banner, the Game Boy stripe) that makes a retro library recognisable, and that branding is what I want to see. We considered OpenVGDB, which OpenEmu and Delta use, but it's unmaintained and its GameFAQs cover links now return 403. libretro-thumbnails is maintained and finds box art for about 97% of my Games, but only through a layered lookup ending in fuzzy title matching. A wrong fuzzy match is accepted silently and fixed by uploading, so uploads are now allowed on any Game. libretro ranks above OpenEmu so the journal leans on OpenEmu less, though keeping OpenEmu isn't decided either way. Box art lives in the cache, unbacked, because it can be fetched again; uploads stay in the journal.

The OpenEmu step has since been dropped from this order; see [0009](0009-ludeum-reads-rom-folders-openemu-is-gone.md).
