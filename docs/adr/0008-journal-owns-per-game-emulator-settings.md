# The journal owns per-Game Emulator settings

Some Games need different Emulator settings (e.g. run-ahead frames for input lag), so the journal stores them per Game, with a default per Emulator, and passes the full set on every Play along with `--doNotSaveSettings` (MesenCE syntax: `--emulation.runAheadFrames=N`). We considered MesenCE's own per-game config, but it only covers DIP switches and overscan. We considered storing a raw list of switches per Game, but MesenCE runs as a single instance and keeps overrides for the rest of the session, so a Game without an override would inherit the previous Game's; the journal can only reset settings it knows about, so it manages a small fixed set and always sends all of them. We considered starting a fresh emulator per Play, but that means killing whatever is running and depends on each emulator's single-instance behaviour. `--doNotSaveSettings` keeps the journal from ever changing the Emulator's own saved preferences.
