# RetroAchievements' times beside IGDB's time to beat

IGDB's time to beat is submitted by its players, so few old Games have one: 178 of my 884 pre-2000 Games. HowLongToBeat has far more, but its owner's terms forbid any automated retrieval without written permission (#94). RetroAchievements has a documented web API, whose terms allow third-party tools to reuse its data and whose docs ask for it to be cached, and its `API_GetGameProgression` gives each set's median time to beat and to master, from the time its players actually spent in the emulator (`docs/research/time-to-beat-sources.md`). Of the 481 library games Wikidata gives a RetroAchievements id, 475 had a beat median from at least 5 players, and 323 of those had no IGDB time. So Game detail shows RetroAchievements' times too (#95).

**Both are shown, each naming its source.** IGDB's line ("Rushed · Normally · 100%") and RetroAchievements' ("Beat · Master") sit under one Time to beat label. Neither replaces the other: they measure different things (what players say they took, and the time achievement hunters spent in the emulator, which runs longer: Super Metroid 8–10 hours), and RetroAchievements has no rushed time. Showing both needs no rule about which wins.

**A set is one console's.** Sonic the Hedgehog 2 has a Mega Drive set (5 hours) and a Game Gear one (1.4), so a Game takes the set on its Platform: each IGDB Platform RetroAchievements has sets for maps to its console (SNES and Super Famicom to one, NES and Famicom to another), and a Game on any other Platform has none. The set is the first that Hasheous, by a checksum of one of the Game's ROMs, ties to a set on that console, as that's the dump I have; only when none does is it the set on that console among those Wikidata gives the Game's IGDB game (P11393, found by its IGDB slug, P5794). Where both gave an id for a library game they agreed 38 times in 44, and Hasheous knew 82 sets Wikidata didn't; Wikidata reaches Games with no ROM.

**A median needs 5 players.** Of softcore and hardcore, the beat time is whichever more players are behind; the master time is mastery (hardcore) or completion (softcore), likewise. Either is left out when fewer than 5 players are behind it (Populous's softcore beat is 17 hours, from one player), and a Game with neither shows only IGDB's.

**Nothing is kept in the journal.** Every answer (Hasheous's, Wikidata's, RetroAchievements') is in the cache, so a Game's time is worked out whenever Game detail shows it, and Matching a ROM or changing its IGDB link changes it with no step to rerun. RetroAchievements' and Wikidata's answers, an unknown set and no ids included, are kept for 180 days, not the cache's usual 60, as set data hardly changes, and the launch refresh asks again only then. At most one request a second to each. A lookup that fails shows no RetroAchievements time and is tried again the next time the Game is shown, with no alert.

**It needs a key.** RetroAchievements' API takes an account's web API key, set in Settings and kept in the Keychain; without one nothing is looked up. The key goes in each request's query, as the API has no other way, so it's left out of every error.

We considered Wikidata alone: one query per Game, no new Hasheous lookups, but it misses the sets only Hasheous knows and has to choose among an item's ids by console anyway. We considered RetroAchievements' own game list per console, matched by title as LaunchBox's box art is, for the Games neither finds: most coverage, but a title can match a hack or a subset, and neither id route can. We considered letting RetroAchievements' time replace IGDB's when both have one, as a median from thousands beats a handful of submissions, but the two don't measure the same thing.
