# LaunchBox Box art after libretro's

libretro-thumbnails has no repo for Windows, the Switch or the Xbox One and later, and only a few dozen boxes for the Xbox 360, PS3 and PS4, so those Games showed IGDB's clean Cover art, or a Bundle's box (Command & Conquer: Red Alert 2 showed The First Decade's). The DOS repo covers PC Games from the Windows 95 era, but nothing newer. Now a Game libretro has no Box art for looks in the LaunchBox Games Database by title, before a Bundle's Cover and IGDB's Cover art: its boxes are retail scans with the platform's branding, like libretro's, which is the look [0006](0006-box-art-before-igdb-cover-art.md) chose Box art for. Matched against my journal, it has a box for 63 of my 75 PC Games and 51 of my 78 Xbox One Games.

We considered TheGamesDB (an API key, a monthly request quota, no terms for its images), ScreenScraper (a developer id to request, tight rate limits), MobyGames (the best PC scans, but its API is now paid) and SteamGridDB (community artwork, not box scans). LaunchBox needs no account: its whole database is one public dump, `Metadata.zip`, and its images are public by file name. There's no published licence for using either outside LaunchBox; this is a personal app, and an upload still fixes or replaces any Cover.

The dump is about 110 MB (575 MB unzipped) and remade daily, but box scans rarely change, so it's read at most every 30 days, by the launch refresh, never on a screen's behalf. Until the first one is read, a Game LaunchBox would have a box for shows what it did before. It's streamed out of the zip rather than unpacked, and only what finds a box is kept: every mapped platform's games, not just the Platforms in my journal, since a Game added on a new Platform would otherwise find nothing for up to 30 days. Keeping each name's title keys and an index on them makes each lookup a query rather than a per-Platform index built in memory, as libretro's is; that's most of the 44 MB. libretro still comes first: its boxes are matched by ROM file name, which is more certain than a title.

**Amended 2026-10-16:** a Game neither source finds a box for by its own names is looked up again, in both, by IGDB's alternative names for it. IGDB names the Commander Keen episodes "Commander Keen in Invasion of the Vorticons: Marooned on Mars" and the like, but lists "Commander Keen 1: Marooned on Mars" as an alternative, which is how libretro and LaunchBox name them. Alternative names come last because they can be a working title another game has: Command & Conquer: Renegade's is Commando, which matches a 1986 game's box in libretro's DOS set, while LaunchBox has Renegade's own.
